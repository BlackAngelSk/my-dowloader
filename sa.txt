You are an expert Software Architect and Senior Full-Stack Developer specialized in high-performance networking, desktop UI design, and multi-protocol file transfer systems.

Your task is to build a modern, ultra-fast, cross-platform modular downloader application called **"OmniDownloader"**.

---

### 1. Core Architecture & Stack Requirements

- **Backend / Engine:** Rust or Python (PyQt6 / PySide6 / `asyncio`) or Node.js (Tauri + Rust/C++ binding for core performance).
- **Frontend / UI:** Modern UI framework with native dark and light mode support (Tailwind CSS + React/Vue via Tauri, OR PyQt6 / CustomTkinter with custom QSS themes).
- **Core Engine Principle:** Maximum disk I/O and network saturation.
  - Multi-threaded segmented downloading (Dynamic Range requests).
  - RAM buffering ($16\text{ MB} - 64\text{ MB}$ memory buffer before flushing to disk) to prevent disk thrashing and maximize write speed up to NVMe/SSD physical limits.
  - Async I/O for zero-blocking UI execution.

---

### 2. Key Modules & Functional Requirements

The app MUST be modular, allowing users or developers to easily add new download providers via a plugin architecture.

#### A. Torrent Module
- Support for `.torrent` files and `magnet:` links.
- Library: `libtorrent` wrapper or native Rust torrent library.
- Features: Peer discovery, DHT, tracker management, sequential download toggle (for media streaming), speed cap settings, and selective file downloading within torrent bundles.

#### B. Video & Social Media Extractor Module
- Powered by `yt-dlp` integration or custom extractors.
- **Supported Platforms:** YouTube (Videos, Playlists, Shorts), Twitter/X (Videos & Images), Facebook, TikTok, Instagram (Reels & Posts), Reddit, Twitch.
- **Features:**
  - Video format/resolution selection (1080p, 4K, 8K, 60fps).
  - One-click Audio Extraction (MP3, AAC, FLAC, M4A).
  - Automatic muxing of Video + Audio tracks using `ffmpeg`.
  - Subtitle auto-downloader.

#### C. Direct File & Batch Image Scraper Module
- Multi-connection HTTP/HTTPS/FTP downloader.
- Dynamic chunk splitting: If file size is $S$ and thread count is $N$, split range into chunks $C_i = [i \cdot \frac{S}{N}, (i+1) \cdot \frac{S}{N} - 1]$.
- **Image Downloader:** Scrapes image galleries from web pages, social media threads, and direct URL lists. Features auto-deduplication, thumbnail preview generation, and batch naming.

RAM Ring Buffer: Accumulate incoming stream packets into a contiguous memory buffer (16 MB−64 MB) before issuing a single sequential disk write block.
Direct Disk Allocation: Pre-allocate the full file size on disk (fallocate on Linux, SetFileValidData on Windows) before downloading begins to prevent file fragmentation.

from abc import ABC, abstractmethod

class BaseDownloaderModule(ABC):
    @abstractmethod
    def can_handle(self, url: str) -> bool:
        """Returns True if this module handles the provided URL or protocol."""
        pass

    @abstractmethod
    async def extract_metadata(self, url: str) -> dict:
        """Returns metadata (title, filesize, thumbnail, available resolutions)."""
        pass

    @abstractmethod
    async def start_download(self, url: str, download_path: str, progress_callback: callable):
        """Starts the downloading process with progress callbacks."""
